# Python Calculator

## Project Description
A simple command-line calculator developed using Python. It allows users to perform basic arithmetic operations by entering two numbers and selecting an operator.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Displays an error for invalid operators
- Supports decimal numbers

## Technologies Used
- Python 3
- Visual Studio Code
- Git and GitHub

## Requirements
- Python 3 installed on your computer

## How to Run the Project

**Step 1:** Clone this repository.

```bash
git clone https://github.com/Anjani-04/Python-Calculator.git
```

**Step 2:** Navigate to the project folder.

```bash
cd Python-Calculator
```

**Step 3:** Run the Python program.

```bash
python calculator.py
```

On Windows, you can also use:

```bash
py calculator.py
```

## Example Output

```text

Enter second number: 20
Result: 30.0
```
